# Store listing screenshots

Both PNGs are 1920 by 1080 captures of Scattered Thoughts' local frontend.

- `capture-composer.png`: the clean, ready-to-capture composer.
- `capture-with-note.png`: the composer with a sample unsaved multiline note.

The sample text is illustrative only and is not stored in the app database.
Use these for the Windows PC Store listing. Additional screenshots should show
real app states only, such as Recent Notes after notes have been captured.
